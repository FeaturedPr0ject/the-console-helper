One-time setup
  1. Open GitHub Actions and download the ServerTrace-NativeHost-win-x64 artifact from the latest successful Build Native CMD Host run.
  2. Copy ServerTrace.NativeHost.exe beside install-native-host.bat in the native-host folder.
  3. Run install-native-host.bat, enter this extension's ID from chrome://extensions, then reload Server Trace.
  4. Return here and press CONNECT CMD.EXE.

Or build it locally with .NET 8 using build-native-host.bat.

Local, passive scan

Requests access only to the specific website when you press Scan. You can deny permission and keep using the isolated JavaScript console.

Inspects resource URLs already recorded by the browser, API-like references in the page, and inline script text.

Does not read cookies, authorization headers, login sessions, or storage values. Does not send requests to discovered endpoints or extract tokens.
